# 💰 Sistema de Gerenciamento de Finanças Pessoais

Um sistema simples, eficiente e prático em Python para controle de receitas, despesas e cálculo de saldo em tempo real com persistência de dados em formato JSON.

---

## 🚀 Funcionalidades

- 🟢 **Adicionar Receitas**: Registre entradas financeiras com descrição, valor e data/hora automática.
- 🔴 **Adicionar Despesas**: Registre saídas financeiras de forma rápida.
- 📊 **Extrato Detalhado**: Visualize todo o histórico de transações com indicativos visuais (verde/vermelho).
- 💵 **Cálculo de Saldo**: Acompanhamento em tempo real do saldo acumulado e status da conta (no azul ou no vermelho).
- 💾 **Persistência de Dados**: As transações são salvas automaticamente em um arquivo `transacoes.json` local.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **JSON** (para armazenamento de dados)
- **Git & GitHub** (para controle de versão)
